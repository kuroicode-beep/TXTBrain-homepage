The Problem

흩어진 파일,
사라지는 맥락

문서가 쌓일수록 찾기는 어려워집니다.
TXTBrain은 흩어진 파일을 조용히 흡수하고,
검색 가능한 구조로 재편합니다.

01 ─────
흩어진 파일들

다운로드, 바탕화면, 임시 폴더에 쌓이는 TXT·DOCX·PDF. 필요한 순간 어디 있는지 알 수 없습니다.

02 ─────
사라지는 맥락

파일 이름만으로는 내용을 알 수 없습니다. 열어보기 전까지 무엇인지 모릅니다.

03 ─────
클라우드 의존

민감한 문서를 외부로 보내기 불편합니다. 인터넷 없이 완전히 작동하는 로컬 솔루션이 필요합니다.

How it works

문서가 신경망으로
흡수됩니다

01
TXT
파일 추가

TXT, DOCX, PDF 파일을 드래그하거나 폴더를 지정합니다.

02
AI
AI 분석

로컬 Ollama 엔진이 문서 내용을 파악하고 구조화합니다.

03
DB
DB 저장

로컬 SQLite DB에 안전하게 저장됩니다. 인터넷 연결 불필요.

04
⌕
즉시 검색

자연어로 질문하면 관련 문서를 즉각적으로 찾아냅니다.

Features

주요 기능

06 FEATURES
AI · LOCAL
로컬 AI 검색

Ollama 기반 로컬 LLM이 문서 내용을 이해하고 자연어 질문에 답합니다. 데이터가 외부로 나가지 않습니다.

→ Ollama
IMPORT
다중 포맷 지원

TXT, DOCX, PDF 파일을 단일 인터페이스에서 관리합니다. 드래그 앤 드롭으로 즉시 추가.

→ TXT / DOCX / PDF
STORAGE
로컬 데이터베이스

모든 데이터는 로컬 SQLite DB에 저장됩니다. 클라우드 없이 완전히 오프라인으로 작동합니다.

→ SQLite
SEARCH
전문 검색

제목, 내용, 날짜 기반 필터로 정밀하게 검색합니다. 수백 개의 파일에서도 즉각적인 결과.

→ Full-text
EXPORT
데이터 내보내기

정리된 문서를 다양한 형식으로 내보냅니다. 아카이브를 원하는 방식으로 활용하세요.

→ Export
I18N
한국어 / English

한국어와 영어를 완벽 지원합니다. 설정에서 언제든지 언어를 전환할 수 있습니다.

→ KO / EN

TXTDrop


TXTDrop은 클립보드 내용을 한 번의 단축키로 저장하는 작은 유틸리티입니다.

Ctrl + Shift + Z 를 누르면 클립보드의 텍스트는 TXT로, 이미지는 PNG로 자동 저장됩니다.

TXTBrain용 자료 수집 도구입니다.
